# Sonali's Portfolio

Build a clean and professional bilingual (English + Korean) portfolio website 

for a software developer named Sonali Sulgadle.

TAGLINE: "Android Developer with 8+ years building scalable mobile applications"

SECTIONS TO INCLUDE:

1. Hero / Header — Name, tagline, and CTA buttons (View Projects, Download Resume)

2. About Me — Short bio in both English and Korean, with a professional photo placeholder

3. Skills — Visual skill cards or progress bars highlighting: Android, Kotlin, 

   Jetpack Compose, Java, and related mobile technologies

4. Work Experience — Timeline layout showing companies, roles, durations, 

   and key achievements

5. Projects — Card-based grid layout with project name, description, 

   tech stack used, and a GitHub link per project

6. Contact / Footer — LinkedIn and GitHub icon links, email, 

   and a simple "Open to opportunities" message in both English and Korean

DESIGN REQUIREMENTS:

- Clean, minimal, and professional aesthetic

- White or light grey background with subtle accent color (navy or dark blue preferred)

- Fully responsive (mobile + desktop)

- Smooth scroll navigation with a sticky top navbar

- Language toggle button (EN / 한국어) to switch between English and Korean content

LINKS TO INTEGRATE:

- GitHub profile link (placeholder: github.com/sonalisulgadle)

- LinkedIn profile link (placeholder: linkedin.com/in/sonalisulgadle)

TONE & AUDIENCE:

- Targeted at Korean tech companies and startups in Seoul

- Professional yet approachable tone

- Korean content should be natural and polished, not machine-translated
